Frequently asked questions

What happens when I hit the free limit? ▾
You'll see a notice letting you know you've reached your daily limit. Limits reset every 24 hours. Upgrade to Pro for unlimited access.
Can I switch between plans? ▾
Yes. Upgrade or downgrade anytime. If you downgrade, you'll keep Pro features until the end of your billing period.
What models do I get on each plan? ▾
Free tier includes Llama 3.1 8B via Groq and local Ollama. Pro adds 65+ models across 12 providers: Llama 70B, RakshakAI 14B, GPT-4o, GPT-4o Mini, Claude, DeepSeek, Gemini, Mixtral, Qwen 72B, Mistral, Grok, Perplexity, and more. Enterprise adds private/custom models.
Is my code stored or used for training? ▾
No. RakshakAI does not store your code. All analysis is ephemeral — processed in memory and discarded immediately. For self-hosted Enterprise deployments, data never leaves your infrastructure.
Do I need an API key? ▾
For the web UI, you can use the server proxy (which has a shared Groq key) or bring your own API key. For the CLI, you'll need to set environment variables. Local Ollama requires no API key at all.
What is RakshakAI 14B? ▾
Our fine-tuned security model based on Qwen2.5-Coder-14B-Instruct. Trained on 87K CWE security examples using QLoRA across 750 steps. Currently at 525/750 steps (70%). It specializes in CWE classification, vulnerability detection, and secure code generation.
Can I use RakshakAI in CI/CD? ▾
Yes. The CLI supports headless JSON mode: rakshak scan src/ --json. Exit codes indicate vulnerability status (0=clean, 1=vulns found). Integrates with GitHub Actions, GitLab CI, Jenkins, and more.
What about refunds? ▾
We offer a 14-day money-back guarantee on Pro plans. No questions asked. Contact rakshak@example.com for refund requests.
How does RakshakAI compare to Claude Code? ▾
RakshakAI's system prompt is 302 tokens vs Claude Code's 30,500 — 101x smaller. Cold start is 50ms vs 3,500ms. RakshakAI is free and open-source, supports 65+ models across 12 providers, and specializes in security vulnerability detection with 248 CWE classes.
